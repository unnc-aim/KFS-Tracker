# 需求文档：基于已知尺寸和相机内参的立方体角点定位与 PnP 计算

## 目标

定位场景中一个红色或蓝色的、几乎纯色立方体的六个外部角点轮廓，并基于已知立方体尺寸和相机内参矩阵，使用 PnP 求解器得到立方体相对于相机的三维坐标。

## 任务描述

输入:
- 一张包含目标立方体的图像
- 立方体真实边长或长宽高尺寸
- 相机内参矩阵（焦距、主点、畸变参数可选）

输出:
- 立方体六个外部角点的二维图像坐标
- 立方体六个外部角点对应的三维世界坐标（相机坐标系下）
- 立方体姿态（旋转向量/矩阵和平移向量）

## 方法思路

### 1. 颜色与候选区域检测

1. 使用颜色空间分离红色/蓝色区域。
   - 可用 HSV 或 Lab 颜色空间。
   - 通过纯色特征设置阈值，形成二值掩码。
2. 形态学处理。
   - 先腐蚀后膨胀去噪。
   - 保留大面积连通域，过滤掉小斑块。
3. 查找候选区域轮廓。
   - 计算轮廓面积和近似多边形。
   - 选取近似矩形或具有 4 个主要边的区域。

### 2. 外部角点轮廓提取

1. 对候选区域做四边形拟合。
   - 使用 `approxPolyDP` 获得四个顶点。
   - 如果轮廓不是规则四边形，可使用 `minAreaRect` 或凸包提取。
2. 验证边缘方向与面积。
   - 计算近似四边形的角度、比例。
   - 筛选出符合立方体投影形状的轮廓。
3. 处理异色图案。
   - 立方体中间的异色图案用于辅助判断面朝向。
   - 可以利用该图案在候选区域内部定位面中心、增强角点排序。

### 3. 六个外部角点的确定

1. 选择外部角点概念。
   - “六个外部角点”通常指可见的六个顶点投影，而非立方体全部八个顶点。
   - 对于一个视角下的立方体，最多可见 6 个顶点，其中 2 个在遮挡面后不可见。
2. 从轮廓和几何信息中确定角点。
   - 先识别四个前景轮廓顶点。
   - 再结合图像深度或投影结构，推断与前景顶点对应的后方顶点。
3. 使用几何约束。
   - 根据立方体已知尺寸，构建可能的三维顶点结构。
   - 通过 2D-3D 配对，选出最合理的 6 个投影角点。

### 4. 构造 3D-2D 对应关系

1. 定义立方体三维坐标系。
   - 例如立方体中心为原点，边长为 `L`。
   - 3D 点可选为顶点：`(±L/2, ±L/2, ±L/2)`。
2. 选择用于 PnP 的 3D 点。
   - 取可见的 6 个顶点对应 3D 点。
   - 保证点对的顺序与 2D 图像点一致。
3. 处理顺序与拓扑。
   - 按角点在图像中的排序（例如左上、右上、右下、左下、后上、后下）保持一致性。

### 5. PnP 求解

1. 准备相机内参矩阵 `K`。
   - `K = [[fx, 0, cx],[0, fy, cy],[0,0,1]]`
   - 若有畸变系数，可同时传递给求解器。
2. 调用 PnP 求解函数。
   - OpenCV 中可使用 `solvePnP`、`solvePnPRansac`。
   - 传入 3D 点、2D 点、相机内参和畸变参数。
3. 获取外参。
   - 返回旋转向量 `rvec` 和平移向量 `tvec`。
   - 可使用 `Rodrigues` 转换为旋转矩阵。
4. 计算三维坐标。
   - 将每个 3D 点转换到相机坐标系：`X_cam = R * X_obj + t`。
   - 如果需要，可进一步换算到世界坐标系。

### 6. 面变换矩阵与实现流程

1. 选定一个可见面。
   - 先识别立方体四个顶点中，构成某一面（如前面、上面或侧面）的四个点。
   - 对于红/蓝立方体，优先选择投影为凸四边形的可见面。
2. 计算原图像中的面点 2D 坐标。
   - 这些点通常来自前景四边形的四个角点。
   - 若存在异色图案，可把图案边界点作为辅助点。
3. 定义目标平面坐标系。
   - 目标矩阵可定义为一个规范矩形平面，如 `[(0,0),(W,0),(W,H),(0,H)]`。
   - 其中 `W` 和 `H` 可为面宽度和高度，单位与输入图像比例一致。
4. 选择变换类型。
   - 仿射变换：适用于面点仍近似平行且无强透视畸变的情况。使用 `getAffineTransform` 需要 3 个点。
   - 透视变换（单应矩阵）：适用于任意可见面，尤其有透视畸变时。使用 `getPerspectiveTransform` 需要 4 个点。
5. 计算图像变换矩阵。
   - 仿射矩阵 `A_affine = getAffineTransform(srcPts, dstPts)`。
   - 透视矩阵 `H_persp = getPerspectiveTransform(srcPts, dstPts)`。
6. 生成变换后的面图像。
   - 使用 `warpAffine` 处理仿射矩阵。
   - 使用 `warpPerspective` 处理透视矩阵。
   - 输出图像尺寸为目标矩形的 `W x H`。

#### 对应实现流程

1. 从立方体候选区域中提取一组面顶点 `srcPts`，顺序一致，如左上、右上、右下、左下。
2. 定义目标平面点 `dstPts`，例如 `[(0,0),(W,0),(W,H),(0,H)]`。
3. 选择变换矩阵类型：
   - 若需要精确保留任意透视效果，使用 `H_persp = getPerspectiveTransform(srcPts, dstPts)`。
   - 若仅需近似变换且三个点足够，使用 `A_affine = getAffineTransform(srcPts[:3], dstPts[:3])`。
4. 对原图做变换：
   - `face_img = warpPerspective(image, H_persp, Size(W, H))`。
   - 或 `face_img = warpAffine(image, A_affine, Size(W, H))`。
5. 验证结果：
   - 检查变换后的面是否为规整矩形。
   - 若目标面图像出现拉伸或畸变，优先选择透视矩阵。

## 实现建议与注意事项

- 颜色区分应避免仅依赖 BGR，因为光照变化大。优先使用 HSV 色相范围和饱和度阈值。
- 如果立方体边缘不明显，可先做 Canny 边缘检测，再结合颜色区域提高鲁棒性。
- 为避免误匹配，可使用 `solvePnPRansac` 提升对噪声和错误点的容错能力。
- 需要校准相机或使用标定好的内参，避免因内参误差导致 pose 计算偏差。
- 立方体的异色图案可用于区分朝向，提高 3D 点序列匹配的可靠性。
- 若图像存在畸变，先做去畸变再进行角点检测和 PnP 计算。

## 验证与测试

1. 重投影误差验证。
   - 将求解得到的 `rvec`、`tvec` 应用到 3D 点。
   - 计算投影到图像平面的误差，应尽量小于一个像素或几个像素。
2. 可视化结果。
   - 在输入图像上绘制 2D 角点和重投影边框。
   - 可视化 3D 坐标轴或立方体边界。
3. 多场景测试。
   - 测试不同角度、距离、光照条件下的鲁棒性。
   - 包含正面、侧面、遮挡部分边缘、异色图案不同位置的情况。

## 扩展与优化

- 增加亚像素角点定位，以提高 PnP 精度。
- 使用多帧融合或滑动窗口方式增强估计稳定性。
- 在检测阶段加入深度信息（若有深度相机）可直接改善 3D 对应匹配。
- 结合机器学习/深度学习模型做立方体实例分割，再提取角点。

---

以上方案适用于“红或蓝几乎纯色立方体，中间有异色图案”的场景，重点在于先获取稳定的 2D 角点，再基于已知尺寸和相机内参执行 PnP 求解。
